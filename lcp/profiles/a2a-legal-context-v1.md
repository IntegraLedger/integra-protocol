**LCP A2A extension `https://lcp.integraledger.com/a2a/legal-context/v1`.** 1. A server that supports it declares it in `capabilities.extensions[]`, and echoes it in `A2A-Extensions` when a client requests it. 2. For a task with an ATR, the server puts `{"type":"sha256","value":H,"legalContextUrl":L}` in the Task's `metadata` under this URI. 3. The client fetches L, hashes what it receives and compares with H before paying. 4. A2A signs nothing per task: what binds H to the payment is the payment protocol used.
