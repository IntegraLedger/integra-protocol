**LCP A2A extension `https://lcp.integraledger.com/a2a/legal-context/v1`.** This extension targets A2A 1.0. 1. A server that supports it declares it in `capabilities.extensions[]`, and echoes it in `A2A-Extensions` when a client requests it. The extension takes no `params`. 2. For a task with an ATR, the server puts `{"type":"sha256","value":H,"legalContextUrl":L}` in the Task's `metadata` under this URI. H is the SHA-256 of the ATR's exact bytes, as `0x` and 64 hex digits, and L is an `https` URL of at most 2048 characters that serves those bytes. The server writes the value when the request's `A2A-Extensions` names this URI; a server may also write it otherwise, and a client that did not activate the extension may ignore it. 3. The client fetches L, hashes what it receives and compares with H before paying. 4. A2A signs nothing per task: what binds H to the payment is the payment protocol used.
