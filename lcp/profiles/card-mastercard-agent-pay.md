**LCP profile `card/mastercard-agent-pay`: the ATR hash in a Mastercard Agent Pay message signature.** Mastercard publishes no Agent Pay acceptance framework. This profile is built from the text Mastercard does publish, its Developer Playbook on preparing for agentic commerce (`https://developer.mastercard.com/merchant-cloud/documentation/tutorials-and-guides/agentic-commerce-guide/21/index.md`, cited `guide-21`, SHA-256 `612d6d0bd3192dc8…`, and `…/24/index.md`, cited `guide-24`, SHA-256 `9626052fd2d0a1df…`, both read 2026-11-16). Until a real sample shows an Agent Pay request with H in place, the form is not confirmed and nobody offers it.

1. Before payment the merchant shows the legal context as `card/visa-tap` rule 1 states it, and the agent checks it as that profile's rule 2 does.
2. The agent's message signature follows Web Bot Auth, as `guide-21:140-167` shows it: an RFC 9421 signature over at least `@authority` and `@path`, with `created`, `expires`, `keyid`, `alg`, `nonce` and `tag`. Its `tag` is Mastercard's, published in two spellings: `Agent-pay-auth` (`guide-21:149`, `:166`, `:172`, `:300`) and `agent-pay-auth` (`guide-24:386`). Both are read.
3. H rides as on `card/visa-tap` (its rule 3): in the signature's `nonce`, the base64 of H's 32 bytes followed by 32 random bytes; or, for an agent whose nonce does not carry H, in the merchant's checkout path, whose last segment is H and which the signature covers as `@path`, the nonce then not read, so an agent that draws 64 random nonce bytes, as the playbook's example request shows (`guide-21:165`), pays by the path.
4. `bound` reads every signature whose `tag` is the String `Agent-pay-auth` or `agent-pay-auth`, by `card/visa-tap`'s rule 4, with its parameter names read by that profile's rule 7. A signature tagged for Visa is not read here.
5. The playbook's own example request (`guide-21:156-167`) carries a nonce of 64 bytes, which `bound` reads as a hash the merchant did not issue; it is this profile's vector (`card.json`, `T6`).
6. The merchant refuses a request whose H it did not issue for this checkout, or whose H it has seen used. The card authorization does not carry H.
